# Hypersonic Skills

Lean skill pack for velocity-routed AI coding work. Start with `hypersonic-core`, then load the focused skill that matches the current phase.

| Skill | Trigger | Job |
|---|---|---|
| `hypersonic-core` | start of coding work, scope changes | classify V1-V4, choose workflow, set verification depth |
| `rapid-build` | prototype, explore, "just build one version" | produce a visible draft quickly |
| `architect` | V3/V4 work needs design | write a short execution brief |
| `surgical-debug` | bug, failure, unexpected behavior | reproduce, isolate root cause, fix narrowly |
| `tdd-engine` | tests or risky behavior change | choose the right test depth and prove behavior |
| `code-review` | review before ship | find correctness, failure, security, performance, and test gaps |
| `ship-it` | commit, PR, push, merge, finalize | verify final state and create clean handoff |
| `evolution-engine` | durable repo learning | update `.hypersonic/learned.md` and history |
| `autopilot` | unattended continuous work | finish plan, then make verified improvements until interrupted |

External reference packs are not part of the active workflow. Borrow ideas only when they improve a Hypersonic skill without adding ceremony.
